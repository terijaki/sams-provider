# Consumer documentation

Integration guides for club apps that receive SAMS provider projection events on their own SQS queue.

- [Event reference](./events.md) — what each event means, when it fires, and payload fields
- [npm package](../../packages/sams-provider-events/) — install `sams-provider-events` for TypeScript types and Zod schemas
- [Registration steps](../../README.md#get-events-for-your-club) — queue setup and GitHub issue

The machine-readable contract is the [`sams-provider-events`](../../packages/sams-provider-events/) npm package (Zod schemas). Prose docs follow that contract.
